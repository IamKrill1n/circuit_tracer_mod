ADR 0005: Draggable Summary Graph Renderer

Status: Accepted

Summary. Render summary graphs as self-contained SVG/JavaScript HTML so supernode cards can be dragged and edges can be rerouted around cards after every move.

Context

The summary graph visualization needs interactive placement: users must be able to drag supernodes to clearer positions while preserving readable directed edges. The previous renderer used Plotly shapes and annotations, which are suitable for static layout but awkward for persistent card dragging and live edge recomputation.

Decision

Keep supernode_graph_figure as the public Python entry point, but return a small HTML figure wrapper with to_html and write_html methods. The emitted document uses SVG groups for cards, prompt tokens, and routed edges. Browser-side pointer events update card positions and recompute edge paths around current card rectangles.

Consequences

The pipeline and FastAPI app can continue embedding HTML without a frontend build step or a Plotly runtime. Tests can still inspect a lightweight compatibility surface for the old figure data and layout. The tradeoff is that future visual features must be implemented in the local SVG renderer rather than by configuring Plotly traces.

Next Steps

If users need saved manual layouts, add an explicit position export/import format rather than relying on browser state.
