\section{Problem Formulation}\label{sec:setup}

A summary of an attribution graph is determined by a pruned subgraph and
a partition of the surviving nodes into supernodes. We state the problem
in five parts. Section~\ref{sec:input} fixes the input.
Section~\ref{sec:output} fixes the output and the induced summarization
graph $G_{SN}$. Section~\ref{sec:desiderata} motivates what makes a
summary good and lists the structural well-formedness constraints that
any valid summary must satisfy. Section~\ref{sec:objective} assembles
the desiderata into a single scalar objective $L$ as the sum of three
losses---coherence, conservation, and complexity---weighted by reported
coefficients. Section~\ref{sec:attr-instance} commits to a concrete
closed form for each loss term. The problem statement and its
instantiation are kept separable from any \emph{solver}: spectral
clustering, $K$-means on stacked edge profiles, greedy modularity, or
the methodology of Section~\ref{sec:solution} may minimise different
surrogates internally, but every solver is scored on the same $L$
defined here.

\subsection{Input}\label{sec:input}

A directed acyclic attribution graph $G = (V, E, W)$ has vertex partition
$V = V_{\text{emb}} \cup V_{\text{mid}} \cup V_{\text{logit}}$ into
embedding, mid-graph, and logit nodes; edge set $E$; and signed weight
matrix $W \in \mathbb{R}^{N \times N}$ with $N = |V|$. We use the
convention that $W_{uv}$ is the weight on the directed edge $u \to v$,
so $W$ is sparse and strictly upper-triangular in any topological
ordering of $V$. Each node carries a layer index $\layer(\cdot)$;
embeddings sit at layer $0$ and logits at the final layer. Two side data
accompany $G$: a token-weight vector $\tau \in \mathbb{R}^{|V_{\text{emb}}|}$
on the source set (normalized SHAP values, $\sum_e \tau_e = 1$) and a
logit-weight vector $\ell \in \mathbb{R}^{|V_{\text{logit}}|}$ on the
sink set, identifying which inputs and outputs the summary should
explain.

\subsection{Output}\label{sec:output}

A \emph{summary} is a triple $(V', E', \varphi)$:
\begin{itemize}[leftmargin=*,topsep=2pt,itemsep=1pt]
\item a pruned subgraph $V' \subseteq V$, $E' \subseteq E \cap (V' \times V')$,
with $V_{\text{emb}} \cup V_{\text{logit}} \subseteq V'$ forced;
\item a partition $\varphi : V' \to \pi(\varphi)$ assigning each surviving
node to exactly one \emph{supernode} $S \in \pi(\varphi)$, with every
$v \in V_{\text{emb}} \cup V_{\text{logit}}$ a singleton supernode.
\end{itemize}
The summary induces the \emph{summarization graph}
$G_{SN} = (\pi(\varphi),\, E^{SN},\, W^{SN})$ whose nodes are the
supernodes and whose adjacency aggregates the surviving weights.
For each ordered pair $(S, T)$ with $S \ne T$, let
\begin{equation}
B_{ST} \;=\; \sum_{(u, v) \in E'} W_{uv}\,
\mathbf{1}[u \in S]\,\mathbf{1}[v \in T]
\label{eq:block-sum}
\end{equation}
be the signed block sum. We retain at most one direction per
unordered pair by keeping the dominant signed mass:
\begin{equation}
W^{SN}_{ST} \;=\;
\begin{cases}
B_{ST} & \text{if } |B_{ST}| > |B_{TS}|, \\
0      & \text{otherwise},
\end{cases}
\quad S \ne T,
\label{eq:wsn}
\end{equation}
so $W^{SN}_{ST} \ne 0$ implies $W^{SN}_{TS} = 0$. The tie case
$|B_{ST}| = |B_{TS}|$ emits no edge in either direction. Setting
$E^{SN} = \{(S, T) : W^{SN}_{ST} \ne 0,\; S \ne T\}$, this construction
eliminates length-2 cycles in $G_{SN}$ by construction; longer cycles
remain a soft target for the DAG cleanup step
(Section~\ref{sec:solution-cluster}). The summarization graph is the
artifact the user reads; $(V', E', \varphi)$ are the decision variables
that produce it.

\paragraph{Mid-graph nodes are feature nodes only.}
In a cross-layer transcoder attribution graph, $V_{\text{mid}}$
originally contains both \emph{feature} nodes (interpretable transcoder
features) and \emph{reconstruction-error} nodes (the residual that the
transcoder fails to capture at each layer/position). Error nodes are not
interpretable as concept-bearing units, so we restrict $V_{\text{mid}}$
to feature nodes throughout: all subsequent references to ``members''
of a supernode, to ``role'' vectors, and to the partition $\varphi$
apply only to feature nodes.

\subsection{What a good summarization graph should be}\label{sec:desiderata}

A reader inspects $G_{SN}$ to recover the model's causal story. The
summary serves the reader to the extent that three conditions hold:
\begin{description}[leftmargin=2.0em,style=nextline,topsep=2pt,itemsep=2pt]
\item[(D1) Coherence.] Members of each supernode share a mechanistic
role---similar influential downstream targets and similar relevant
upstream sources---so each supernode can be read as a single concept.
\item[(D2) Conservation.] $G_{SN}$ preserves the causal mass that flows
in the original graph from $V_{\text{emb}}$ to $V_{\text{logit}}$, so
the summary is not an artefact of what was discarded.
\item[(D3) Complexity.] $G_{SN}$ is small enough to read in one sitting,
so the user spends attention on supernodes that exist rather than on
a chain of them that exceeds working memory.
\end{description}

Beyond these three, a summary must be \emph{structurally well-formed},
independent of any loss:
\begin{description}[leftmargin=2.0em,style=nextline,topsep=2pt,itemsep=2pt]
\item[(F1) DAG integrity.] $G_{SN}$ is acyclic.
\item[(F2) Partition well-formedness.] $\varphi$ is a function (each
$v \in V'$ in exactly one supernode); embedding and logit nodes are
singletons.
\end{description}
(F1) and (F2) are hard properties any valid summary must satisfy,
regardless of which loss instantiation or solver is in play. Soft
surrogates (penalty terms, dual variables) are introduced only by
specific solvers; the problem statement treats them as hard.

\subsection{Objective}\label{sec:objective}

We turn the three desiderata into a single scalar objective. Each
desideratum corresponds to one loss term constructed to live in
$[0, 1]$ (Section~\ref{sec:attr-instance}), and the objective is their
weighted sum:
\begin{equation}
\min_{(V', E', \varphi)}\;
L(V', E', \varphi)
\;=\;
\lambda_{\text{coh}}\, L_{\text{coh}}
\;+\;
\lambda_{\text{cons}}\, L_{\text{cons}}
\;+\;
\lambda_{\text{cplx}}\, L_{\text{cplx}},
\quad
\lambda_{\text{coh}} + \lambda_{\text{cons}} + \lambda_{\text{cplx}} = 1,\;
\lambda_i \ge 0,
\label{eq:Lsum}
\end{equation}
with the simplex constraint leaving two free parameters;
we treat $\lambda_{\text{cplx}} = 1 - \lambda_{\text{coh}} -
\lambda_{\text{cons}}$ as derived and report the pair
$(\lambda_{\text{coh}}, \lambda_{\text{cons}})$ alongside results.
Since each $L_i \in [0,1]$ and the weights form a probability simplex,
$L \in [0, 1]$. The term names match the desiderata:
\begin{description}[leftmargin=2.0em,style=nextline,topsep=2pt,itemsep=2pt]
\item[$L_{\text{coh}}(\varphi;\, V', E')$.] Within-supernode disagreement
on mechanistic role---measures (D1).
\item[$L_{\text{cons}}(V', E', \varphi;\, G)$.] Causal mass lost when
$G$ is replaced by $G_{SN}$---measures (D2).
\item[$L_{\text{cplx}}(V', E', \varphi)$.] Visual complexity of the
summarization graph---measures (D3).
\end{description}

\paragraph{Why scalar, not multi-objective.}
A vector-valued formulation $(L_{\text{coh}}, L_{\text{cons}},
L_{\text{cplx}})$ with Pareto dominance lets two trivial partitions sit
on the Pareto front by construction. Singletons (every feature its own
supernode) score $L_{\text{coh}} = 0$ and $D_{\text{agg}} = 0$ while
maxing out $L_{\text{cplx}}$; full collapse into one supernode does the
reverse. Neither extreme is a useful summary, but Pareto comparison
cannot prefer a balanced partition over them. The weighted
sum~\eqref{eq:Lsum} penalises the maxed-out axis of each trivial
partition directly. The individual $L_\ast$ are still reported in
evaluation (Section~\ref{sec:eval}) for diagnostic purposes; ranking
uses the scalar $L$. Section~\ref{sec:attr-instance} fixes the closed
form of each $L_\ast$.

\section{Instantiation for the Transcoder Attribution Graph}\label{sec:attr-instance}

The losses of Section~\ref{sec:objective} are abstract. We now define each
one concretely for the transcoder attribution graph, where feature nodes
correspond to transcoder features and edge weights $W_{uv}$ encode the
linear causal contribution of $u$ to $v$ under the cross-layer
transcoder linearization. The point of this section is to pin down
\emph{what} is being measured; the survey of solvers and their surrogate
forms is the subject of Section~\ref{sec:solution}.

\subsection{Coherence}\label{sec:attr-coh}

The \emph{role} of a feature $u \in V'_{\text{mid}}$ is its pair of
weighted outgoing and incoming edge profiles, with each coordinate
scaled by the causal importance of its endpoint:
\begin{align}
(v_u^{\text{out}})_k &= W_{uk}\,\sqrt{\mathrm{Inf}_k} \nonumber \\
(v_u^{\text{in}})_k  &= W_{ku}\,\sqrt{\mathrm{Rel}_k} \nonumber \\
r(u) &= \bigl[\,v_u^{\text{out}}\,;\, v_u^{\text{in}}\,\bigr] \in \mathbb{R}^{2N}.
\label{eq:role}
\end{align}
Here $\mathrm{Inf}_k$ and $\mathrm{Rel}_k$ are the per-node influence
and relevance scores, named here and defined formally in
Section~\ref{sec:solution-prune}. Outgoing coordinates are weighted by
the \emph{downstream} importance of their target
($\sqrt{\mathrm{Inf}_k}$), incoming coordinates by the \emph{upstream}
importance of their source ($\sqrt{\mathrm{Rel}_k}$), so the role vector
concentrates on the edge dimensions that actually carry causal mass.

The coherence loss is the mean rectified-cosine distance of each
member's role to its supernode centroid, normalised to $[0, 1]$:
\begin{equation}
L_{\text{coh}}(\varphi)
\;=\;
\frac{1}{|V'_{\text{mid}}|}
\sum_{S \in \pi(\varphi)}\; \sum_{u \in S}
\bigl[\,1 - \cos_{+}\!\bigl(r(u),\, \bar r(S)\bigr)\,\bigr],
\label{eq:Lcoh}
\end{equation}
where $\bar r(S) = \frac{1}{|S|}\sum_{u \in S} r(u)$ is the supernode
centroid in role space and $\cos_{+}(x, y) = \max\!\bigl(0,\, \cos(x,
y)\bigr) \in [0, 1]$ is the rectified cosine. The cosine form is
scale-invariant in $W$ (multiplying $r(u)$ by a positive constant
leaves $L_{\text{coh}}$ unchanged), and rectifying then averaging over
features keeps the loss in $[0, 1]$ for commensurate combination with
the other two terms in~\eqref{eq:Lsum}.

\subsection{Conservation}\label{sec:attr-cons}

Edges in an attribution graph carry signed linear contributions;
composing them along directed paths gives the causal mass that reaches
$V_{\text{logit}}$ from $V_{\text{emb}}$. Conservation is measured in
the same units. Working with magnitudes $|W|$, define the outgoing
transition matrix
\begin{equation}
P^{\text{out}}_{uv}
\;=\;
\frac{|W_{uv}|}{\sum_{w : (u, w) \in E'} |W_{uw}|}
\label{eq:Pout-reform}
\end{equation}
for each non-sink $u \in V'$, and the source vector $F^{\text{src}}$
equal to $\tau$ on $V_{\text{emb}}$ and zero elsewhere. The node-level
flow $\mathrm{Flow}(u) = [F^{\text{src}\top}(I - P^{\text{out}})^{-1}]_u$
is well-defined on a DAG and satisfies a per-node conservation law plus
the end-to-end identity $\sum_{\ell \in V_{\text{logit}}} \mathrm{Flow}(\ell)
= 1$ on the original (unpruned) graph. Aggregating to supernodes,
$\mathrm{Flow}^{SN}(S) = \sum_{u \in S} \mathrm{Flow}(u)$, similarly
balances at every interior supernode of $G_{SN}$. Full statements,
proofs, and the supernode lift are deferred to the flow note that
accompanies this paper.

A summary loses causal mass in two distinct ways.

\paragraph{Pruning loss.}
Edges and nodes removed in the cut to $(V', E')$ carry flow that no
longer reaches a logit. The fraction of source mass that survives
pruning is the \emph{flow completeness}
\begin{equation}
\mathcal{C}(V', E')
\;=\;
\sum_{\ell \in V_{\text{logit}}} \mathrm{Flow}_{V'}(\ell)
\;\in\; [0, 1],
\label{eq:Ccal}
\end{equation}
where $\mathrm{Flow}_{V'}$ denotes flow computed on the pruned graph
with $\tau$ restricted and renormalized. $\mathcal{C}(V', E')$ depends
only on $(V', E')$ and is partition-invariant.

\paragraph{Aggregation loss.}
Contracting features into supernodes destroys edge weight in three
ways. Edges between members of the same supernode become self-loops
and are dropped from $G_{SN}$. Edges between members of different
supernodes sum with sign inside each block $B_{ST}$
(Eq.~\eqref{eq:block-sum}), so opposing-sign edges from $S$ to $T$
partially or fully cancel. Finally, the dominant-direction tie-breaker
of Eq.~\eqref{eq:wsn} zeroes the weaker direction of every unordered
pair, removing $\min(|B_{ST}|, |B_{TS}|)$ of mass per pair. All three
forms of loss are visible directly on the retained magnitudes:
\begin{equation}
D_{\text{agg}}(\varphi)
\;=\;
1 \;-\;
\frac{\sum_{(S, T) \in E^{SN}} \lvert W^{SN}_{ST} \rvert}
     {\sum_{(u, v) \in E'} \lvert W_{uv} \rvert}.
\label{eq:Dagg}
\end{equation}
The numerator is the total magnitude of inter-supernode weight retained
in $G_{SN}$ after sign cancellation and tie-breaking; the denominator
is the total edge magnitude in the pruned graph.
$D_{\text{agg}}(\varphi) \in [0, 1]$, with $0$ iff every pruned edge is
preserved as a same-sign contribution to a single directed
inter-supernode block, and $1$ iff every pruned edge is absorbed (for
example $|\pi(\varphi)| = 1$, all mid-graph features in one supernode).

\paragraph{Conservation loss.}
Combining the two and averaging so the result lives in $[0, 1]$:
\begin{equation}
L_{\text{cons}}(V', E', \varphi)
\;=\;
\tfrac{1}{2}\Bigl[\,
\underbrace{\bigl(1 - \mathcal{C}(V', E')\bigr)}_{\text{prune loss}}
\;+\;
\underbrace{D_{\text{agg}}(\varphi)}_{\text{aggregation loss}}
\,\Bigr].
\label{eq:Lcons}
\end{equation}
The prune-loss term is the price of pruning and depends on $(V', E')$
and on the source vector $\tau$; the aggregation-loss term is the
price of grouping and depends only on $\varphi$ given $(V', E')$. No
similarity matrix, signature reweighting, or spectral relaxation
appears in either definition.

\paragraph{Fairness caveat on $\tau$.}
$D_{\text{agg}}$ is structural: it depends only on the signed edge
weights $W$ and the partition $\varphi$, with no role for $\tau$ or
$\ell$, so the aggregation half of $L_{\text{cons}}$ is fairness-clean. The
prune-loss half $1 - \mathcal{C}$ is not: it is precisely the
fraction of $\tau$-injected mass that fails to reach a logit, which
makes $\mathcal{C}(V', E')$ equal to the relevance-reachability of
$V_{\text{logit}}$. Our current pipeline sets $\tau$ to SHAP values,
so the prune loss inherits the bias of an external attribution
method. We treat $\tau$ as a free parameter of the problem
statement---any nonnegative distribution on $V_{\text{emb}}$ with
$\sum_e \tau_e = 1$ is admissible---and we flag a principled fairness
fix as open work: candidate alternatives include uniform $\tau =
1/|V_{\text{emb}}|$, a backward influence-side flow rooted at
$V_{\text{logit}}$ with logit weights $\ell$, and a two-sided
symmetrization combining forward and backward completeness.

\subsection{Complexity}\label{sec:attr-cplx}

A reader inspects the summary one supernode at a time. The relevant
complexity is the number of feature supernodes in $G_{SN}$,
normalised by the size of the unsummarised feature set:
\begin{equation}
L_{\text{cplx}}(V', E', \varphi)
\;=\;
\frac{|\pi(\varphi)| - |V_{\text{emb}}| - |V_{\text{logit}}|}
     {|V'_{\text{mid}}|}.
\label{eq:Lcplx}
\end{equation}
Embedding and logit nodes are forced singletons by~(F2) and do not
change with $\varphi$, so the numerator is exactly the number of
feature supernodes---the quantity each solver calls ``$K$''. $L_{\text{cplx}}
\in [1/|V'_{\text{mid}}|, 1]$, with the minimum at full collapse
($K = 1$, every mid-graph feature in one supernode) and the maximum
at singletons (every feature its own supernode). No edge weights, no
$\tau$, and no $\ell$ enter the definition, so $L_{\text{cplx}}$ is
fairness-clean in the sense of the caveat in
Section~\ref{sec:attr-cons}.

\section{Evaluation Methodology}\label{sec:eval}

A candidate output of the pipeline is a triple $(V', E', \varphi)$
produced by a choice of \emph{token-weight normalization} (input to
pruning) and a choice of \emph{clusterer} (operating on the pruned
graph). Section~\ref{sec:eval-graph} states the headline evaluation:
every $(V', E', \varphi)$ is scored on the same set of per-axis losses,
arranged as a single table indexed by these two choices. Section~\ref{sec:eval-protocol}
states the comparison protocol that produces each table row.

\subsection{Summarization graph evaluation}\label{sec:eval-graph}

\paragraph{Objective-aligned losses.}
Every $(V', E', \varphi)$ is scored on the same five numbers regardless
of which surrogate the solver minimised internally:
$L_{\text{coh}}(\varphi)$ from Eq.~\eqref{eq:Lcoh},
$D_{\text{agg}}(\varphi)$ from Eq.~\eqref{eq:Dagg},
the prune-loss component $1 - \mathcal{C}(V', E')$ from
Eq.~\eqref{eq:Ccal}, $L_{\text{cplx}}(\varphi)$ from
Eq.~\eqref{eq:Lcplx}, and the scalar $L(\varphi)$ from
Eq.~\eqref{eq:Lsum}. The scalar $L$ is the primary ranking column; the
per-axis losses identify which axis a given configuration wins or loses
on.

\paragraph{Construction-bias caveat on $L_{\text{coh}}$.}
Our spectral method, ASG-agglomerative, Spectral-cosine, and Spherical
$K$-means all cluster on the same Inf/Rel-weighted role vectors $r(u)$
of Eq.~\eqref{eq:role}, so the four share a construction advantage on
$L_{\text{coh}}$. We report a method-neutral surrogate alongside,
\emph{steering-coherence}
\begin{equation}
\tilde{L}_{\text{coh}}(\varphi)
= \frac{1}{|V'_{\text{mid}}|}
  \sum_{S \in \pi(\varphi)} \sum_{u \in S}
  \bigl[\,1 - \cos_{+}\!\bigl(\Delta_u,\, \bar\Delta(S)\bigr)\,\bigr],
\label{eq:Lcoh-tilde}
\end{equation}
which substitutes $r(u)$ with the per-feature logit-perturbation vector
$\Delta_u$ obtained by ablating $u$ and reading off the target-logit
change. No solver clusters on $\Delta_u$, so $\tilde{L}_{\text{coh}}$
discriminates structured partitions from cosmetically tight ones.

\paragraph{Headline table.}
The two pipeline choices form the two row axes of a single table:
\begin{itemize}[leftmargin=*,topsep=2pt,itemsep=1pt]
\item \textbf{Token-weight normalization} ($\tau$): \textbf{softmax}
(dense distribution over input tokens) or \textbf{entmax} (sparse,
concentrated on high-SHAP tokens). This choice changes $\tau$, which
feeds $\mathrm{Rel}$ and therefore changes the pruner output that every
clusterer sees.
\item \textbf{Clusterer}: one of ASG-arith, ASG-harm, ASG-geo (spectral),
ASG-agglomerative, Greedy modularity, Spectral-cosine, Spherical
$K$-means.
\end{itemize}
Columns report $L_{\text{coh}}$, $\tilde{L}_{\text{coh}}$,
$D_{\text{agg}}$, $1 - \mathcal{C}(V', E')$, $L_{\text{cplx}}$, and the
scalar $L$. Bold marks the best entry per column. The single table
answers two questions at once---``which token weighting produces a
better-prunable graph?'' and ``which clusterer best summarises that
graph?''---without a separate pruning table.

\paragraph{External utility.}
Two further metrics live outside the optimisation problem but are the
practical reason summarisation is useful. A \emph{semantic-coherence}
score asks an LLM judge to rate each supernode in $[0, 1]$ given the
auto-interpretation of its member features, averaged over supernodes. A
\emph{steering} score scales the activations of all features in a
supernode by a common factor at inference time and reports the
resulting target-logit shift; a useful supernode produces predictable,
concept-aligned shifts. Both are reported as a smaller secondary
table.

\paragraph{Flow-based metrics.}
The companion flow note (\texttt{measure.tex}) derives a family of
graph-intrinsic faithfulness measures---flow completeness
$\mathcal{C}_{\mathrm{Flow}}$, faithfulness correlation
$\mathrm{FaithCorr}_{\mathrm{Flow}}$, deletion- and insertion-curve
areas $\mathrm{Flow}\text{-}\mathrm{DAUC}/\mathrm{IAUC}$, monotonicity
$\mathrm{Mono}$, sufficiency $\mathrm{Suff}_k^{\mathrm{Flow}}$ and
comprehensiveness $\mathrm{Comp}_k^{\mathrm{Flow}}$---that score
$\varphi$ using only $(V', E', \varphi)$ and $\tau$ without forward
passes through the model. \textit{[TODO: integrate the flow-based
metrics from \texttt{measure.tex} into the headline table.]}

\subsection{Comparison protocol}\label{sec:eval-protocol}

\paragraph{Fixed pruner cell per row.}
Within a single (token-weight normalization) block of the table, every
clusterer sees the same pruned graph $(V', E')$, so the prune-loss
$1 - \mathcal{C}(V', E')$ is a column constant within that block and
varies only across normalizations.

\paragraph{Per-solver best-configuration reporting.}
Each clusterer has its own hyperparameter space; we sweep exhaustively
and report \emph{only the best configuration per solver} per block:
\begin{itemize}[leftmargin=*,topsep=2pt,itemsep=1pt]
\item \textbf{ASG-spectral (ours)}: number of clusters $K$, mean
operator $F_{\text{mean}} \in \{\text{arith}, \text{harm}, \text{geo}\}$,
layer-decay rate $\lambda \in [0, 1]$.
\item \textbf{ASG-agglomerative}: same $K, F_{\text{mean}}, \lambda$,
with agglomerative linkage replacing the spectral relaxation.
\item \textbf{Greedy modularity}: $K$ on the symmetrized weighted
adjacency.
\item \textbf{Spectral-cosine}: $K$, rectified-cosine affinity on
$r(u)$.
\item \textbf{Spherical $K$-means}: $K$ on unit-normalised $r(u)$.
\end{itemize}
``Best'' is decided by the scalar $L$ under a single fixed weight
pair $(\lambda_{\text{coh}}, \lambda_{\text{cons}})$ (with
$\lambda_{\text{cplx}} = 1 - \lambda_{\text{coh}} - \lambda_{\text{cons}}$
derived), applied identically to every solver in every block.

\paragraph{Shared $K$ candidate set.}
$K$ ranges over an eigengap-bounded candidate set common to every
solver, computed once per pruned graph. Different solvers may select
different $K^\star$, which is permitted: matching $|\pi(\varphi)|$
across solvers would force sub-optimal configurations on methods whose
natural granularity differs, and $L_{\text{cplx}}$ already accounts for
granularity.
