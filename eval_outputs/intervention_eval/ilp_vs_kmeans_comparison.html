Exp B — ILP supernodes vs. a K-matched K-means baseline

Dataset: analogies / softmax / alpha_0.50 / node_0.02 · 100 pruned graphs · Exp B (constrained-steering causal validation) only · paired per graph · factor −1, window [l, l+1] (Fig. 9), attention & LN frozen.

Headline (honest negative result): at equal granularity (K forced identical per graph — mean K = 15.3, exact match on 100/100 graphs), the simple baseline — K-means on φ role vectors — is more causally faithful per edge than the proposed ILP clusterer on these Exp B metrics. K-means wins edge sign-consistency (0.941 vs 0.878), edge monotonicity (ρ 0.539 vs 0.442), and per-supernode logit effect (0.190 vs 0.175) — all paired Wilcoxon p < 0.01.

The one axis where ILP wins is structure exposed: it surfaces ~1.6 more nonzero causal edges per graph (14.6 vs 13.0; 87/100 graphs), because its λ_causal term is designed to keep causally-connected features in separate supernodes (criterion D3) rather than collapsing the edge inside a cluster. That same mechanism is what drags its per-edge consistency down — see the caveat below.

⚠ How to read this — the metric partly favours K-means by construction

This is a fair test of per-edge faithfulness at equal K, but it is not a verdict that K-means produces better supernodes. Two confounds favour K-means:

  • Hidden hard cases. ILP's λ_causal term deliberately splits causally-connected features across supernodes (D3: keep the edge visible). K-means instead collapses many of those connected features into one cluster, so the weak/ambiguous edges between them are never surfaced as supernode edges — they are hidden inside the cluster and never graded. ILP exposes ~1.6 more edges/graph and is then scored on those extra, inherently noisier edges. K-means is graded only on its cleaner, stronger edges.
  • Tautology risk. Exp B rewards supernodes whose steering response is coherent and sign-predictable. K-means optimises φ role-vector cohesion directly, which is close to what "coherent steering response" measures — so it is partly being graded on its own objective.

Net: both methods are highly faithful (|w|-weighted sign-consistency > 0.86 pooled). The real ILP value proposition — trading atomicity against causal-edge visibility via λ_causal — is a curve, not this single point. This run used λ_causal = 1.0.

This traces whether ILP can dominate K-means at some operating point, and connects Exp B to the Stage-2 atomicity-vs-causal Pareto front (eval/pareto_curve.py).
