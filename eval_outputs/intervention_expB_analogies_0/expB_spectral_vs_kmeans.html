Exp B — Supernode causal validation: our spectral vs k-means baseline

Graph: generated_graphs/analogies_0.pt · Qwen3-4B + mwhanna/qwen3-4b-transcoders · both methods at the same auto-k (k = 3 feature supernodes) · eval/eval_intervention.py

TL;DR. On the same pruned circuit and the same supernode count (k=3), spectral clustering produces three causally load-bearing supernodes — negating any one of them sharply suppresses the target token "Jordan" (mean |Δp| = 0.75). The k-means baseline instead collapses almost all answer-relevant features into a single supernode: one of its three supernodes drives the target (Δp = −0.96) while the other two are causally inert (|Δp| ≤ 0.03), giving mean |Δp| = 0.33. Spectral also has marginally higher edge sign-consistency (0.993 vs 0.979).

1. Setup

  • Prompt (Qwen chat format): … abuja is to nigeria as amman is to? → target logit "Jordan", original p = 0.957.
  • Pruning: prune_attr_graph, node_threshold = 0.02, edge_threshold = 0.95, geometric combine / rank norm, α = 0.5, logit_weights = target (matches the established analogies …_node0.02 setting). → 98 nodes, 58 feature nodes, 3826 edges.
  • k: find_best_k (spectral, swept 2–6) → k = 3. The k-means baseline is run at this same k, so the comparison is at equal granularity.
  • Exp B: negate each feature supernode (factor = −1: value = −orig_activation) over the direct-effect window [l, l+1] (paper Fig. 9), with attention frozen; measure the effect on every other supernode and on the target token. Exp D skipped (--skip-exp-d).

Both methods cluster the identical 58 middle nodes; only the assignment differs (spectral on signed-cosine causal affinity, k-means on φ-vectors). Supernode indices are per-method and not comparable across methods.

5. Interpretation

  • Spectral yields a balanced, causally-coherent decomposition. At k=3 it splits the 58 features so that each supernode is individually necessary for "Jordan" and each wires positively into the target logit. This is the behaviour the supernode abstraction is meant to expose.
  • K-means under-uses its budget. Clustering on φ-vectors puts nearly all answer-relevant features into one supernode and spends the other two on causally-inert groups, so 2 of 3 supernodes carry almost no causal weight on the output.
  • Edge faithfulness is high for both (≥0.98) — both respect the pruned adjacency's signs — but spectral is marginally higher and, more importantly, has more non-trivial edges to be faithful about.

6. Limitations

  • Single graph, single k (=3). The Spearman edge–effect correlation is not meaningful at this scale (too few feature→feature edges); conclusions rest on target/logit Δp and sign-consistency.
  • Pruning used uniform token weights (no SHAP), unlike the …_node0.02_softmax runs; this only changes which nodes survive, identically for both methods.
  • k-means supernode indices are arbitrary; "SN_0 carries everything" is a property of the partition, not of any fixed index.

7. Next steps

  • Repeat across more analogies graphs (and a denser prune, e.g. node_threshold 0.05–0.10 → k=3–5) to turn the single-graph signal into a distribution; aggregate mean |Δp| and # inert supernodes per method.
  • Add agglomerative / ilp and the other baselines (modularity, spectral-cosine) to the same table for a full method sweep.
  • Run Exp D (drop --skip-exp-d) for intra/inter-cluster logit-direction cohesion as a complementary, non-causal cohesion metric.
