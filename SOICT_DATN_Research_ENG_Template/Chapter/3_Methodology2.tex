\section{Overview}

Chapter 2 established the foundation of the circuit tracing backbone that construct the attribution graphs, and the difficulty of interpreting them. Chapter 3 presents the proposed automated summarization method for
turning such an attribution graph into a smaller \emph{summary graph} whose nodes
represent groups of related features and whose edges preserve the main causal
flow. The method has three stages. \textbf{Pruning} removes unimportant attribution-graph
nodes and edges. \textbf{Clustering}
groups functionally similar features into supernodes, further reduce the complexity while preserving causal information. \textbf{Interpreting} aggregates
the clustered graph into a directed acyclic summary graph and assigns
labels to its supernodes. Section~\ref{sec:problem} formalizes the input, output,
and the desiderata of the summary. Section~\ref{sec:method}
then defines the three stages of the method in sequence.
Figure~\ref{fig:methodology-pipeline} gives an overview of the pipeline on the
``Dallas $\to$ Austin'' example.

\section{Problem Formulation}
\label{sec:problem}

\subsection{Input}

The attribution graph is a Directed Acyclic Graph (DAG) $G = (V, E, W)$ for one prompt and one model
prediction. Its node set is partitioned as
\[
V = V_{\text{emb}} \cup V_{\text{feature}} \cup V_{\text{error}} \cup
V_{\text{logit}},
\]
where embedding nodes represent input-token sources, feature nodes represent
transcoder features, error nodes represent reconstruction residuals, and logit
nodes represent output targets. The weighted adjacency matrix
$W \in \mathbb{R}^{N \times N}$, with $N := |V|$, follows the convention
that $W_{ij}$ is the signed linear influence from source node $i$ to target
node $j$. Embedding and error
nodes are sources with no incoming edges, logit nodes are sinks with no outgoing
edges, and feature nodes carry signal between them.

The input also include extra information of feature nodes such as: max activating contexts, top logits, activation frequency.

The token weight vector $\tau \in \mathbb{R}^N$ marks
the input tokens of interest and satisfies $\sum_e \tau_e = 1$ over the selected
embedding nodes. The logit weight vector $\ell \in \mathbb{R}^N$ marks the output
positions or target logits of interest. The vector $\tau$ is initialized using
normalized SHAP values. For a multi-target summary, $\ell$ is initialized using
logit probabilities; for a single-target summary, it assigns weight 1 to the
target logit and weight 0 to all other nodes. This thesis mainly studies the
single-target case.

\subsection{Output}

The output is a \emph{summary graph} $H = (V_H, E_H, W_H)$. Its node set
$V_H = \{C_1, C_2, \dots, C_K\}$ consists of \emph{supernodes}, where each
supernode is a nonempty subset of the non-error attribution-graph nodes:
\begin{equation}
V_H \subseteq \mathcal{P}\!\left(V \setminus V_{\text{error}}\right)
\setminus \{\emptyset\}.
\label{eq:summary-node-set}
\end{equation}
Writing $U_H := \bigcup_{C \in V_H} C$ for the attribution-graph nodes covered
by the summary, admissible supernodes satisfy
\begin{equation}
C_i \cap C_j = \emptyset \quad (i \ne j),
\qquad
\forall v \in U_H \cap (V_{\text{emb}} \cup V_{\text{logit}}),\; \{v\} \in V_H.
\label{eq:supernode-conditions}
\end{equation}
Therefore $V_H$ forms a partition of the represented subset
$U_H \subseteq V \setminus V_{\text{error}}$. Embedding and logit nodes are
represented only as singleton supernodes, so only feature nodes may be grouped.
The edge set $E_H$ and signed weights $W_H$ describe the net causal influence
between supernodes.

\subsection{Desiderata of the summary graph}

A useful summary graph scores high in both interpretability and faithfulness, that is it must be small enough to inspect while still representing
the causal computation of the original attribution graph. Four desiderata make
this requirement explicit.
\begin{description}[leftmargin=2.0em,style=nextline,topsep=2pt,itemsep=3pt]
\item[(D1) Importance retention.] The summary should retain the nodes and edges
that lie on high-mass pathways from the selected input tokens to the selected
logits, and discard nodes and edges that do not contribute to those pathways.
\item[(D2) Atomicity.] Each supernode should represent one causal role. Its
member features should have similar signed downstream targets and similar signed
upstream sources, so the reader can interpret the supernode as a single
mechanism.
\item[(D3) Causal-information preservation.] Causal relations between retained
nodes should remain visible as edges between supernodes when possible. If two
directly connected nodes are merged into one supernode, their edge becomes
internal and no longer appears in $H$.
\item[(D4) Interpretability.] The final graph should be a directed acyclic graph
with few enough supernodes for manual inspection. Acyclicity is required because
the summary is intended to show a forward causal story.
\end{description}

\section{Method}
\label{sec:method}
\subsection{Pruning}
\label{sec:stage1}

Pruning reduces the attribution graph before clustering. This stage targets D1:
it keeps nodes and edges that participate in the selected input-to-output
computation, and removes the rest so that later stages operate on a tractable
subgraph. The pruning rule is based on two path-reachability scores, influence and
relevance, followed by a retained-mass selection rule.

\paragraph{Influence and relevance.}
Influence measures how strongly a node can reach the selected logits, while
relevance measures how strongly a node is reached from the selected input tokens.
Let
\[
W^{\text{in}}_{ij} = \frac{|W_{ij}|}{\sum_k |W_{kj}|},
\qquad
W^{\text{out}}_{ij} = \frac{|W_{ij}|}{\sum_k |W_{ik}|}
\]
be the column-normalized and row-normalized absolute adjacency matrices. The
per-node influence and relevance vectors are
\begin{align}
\mathrm{Inf} &= \ell^\top \bigl(I - (W^{\text{in}})^\top\bigr)^{-1}
= \ell^\top \sum_{k \ge 0} \bigl((W^{\text{in}})^\top\bigr)^k
\;\in\; \mathbb{R}^N, \label{eq:inf}\\
\mathrm{Rel} &= \tau^\top \bigl(I - W^{\text{out}}\bigr)^{-1}
= \tau^\top \sum_{k \ge 0} (W^{\text{out}})^k
\;\in\; \mathbb{R}^N. \label{eq:rel}
\end{align}
Because $G$ is a DAG, both normalized adjacency matrices are nilpotent after a
topological ordering of the nodes. The Neumann series therefore terminates after
finitely many terms, so the inverse expressions are well-defined.

\paragraph{Importance score.}
A node is important only when both scores are high: it must be connected to the
selected input context and also influence the selected output. After normalizing
influence and relevance to $[0,1]$ across nodes, the node importance score is
\begin{equation}
\mathrm{Imp}_v =
\widehat{\mathrm{Inf}}_v^{\,\alpha}\,
\widehat{\mathrm{Rel}}_v^{\,1-\alpha},
\qquad \alpha \in [0,1],
\label{eq:importance}
\end{equation}
where $\widehat{\,\cdot\,}$ denotes the rank normalized score. The geometric mean is
used because it agressively punish nodes with small influence score or relevance score. Edges are scored by applying the same
influence--relevance principle to their source and target endpoints.

\paragraph{Threshold selection}
The pruning stage keeps the highest-importance nodes whose cumulative importance
mass reaches a retained-mass fraction $\eta_V \in [0,1]$, and keeps edges by the
analogous retained-mass fraction $\eta_E$. Equivalently, if $V'$ and $E'$ are the
retained nodes and edges, they are chosen so that
\begin{align}
\frac{\sum_{v \in V'} \mathrm{Imp}_v}
     {\sum_{v \in V} \mathrm{Imp}_v}
&\ge \eta_V, \label{eq:node-retained-mass}\\
\frac{\sum_{(u,v) \in E'} \mathrm{Imp}_{uv}}
     {\sum_{(u,v) \in E} \mathrm{Imp}_{uv}}
&\ge \eta_E. \label{eq:edge-retained-mass}
\end{align}
The implementation obtains these sets by sorting nodes and edges by importance in
descending order and keeping the smallest prefix whose cumulative importance mass
reaches the corresponding fraction. Larger values of $\eta_V$ and $\eta_E$ retain
more of the original graph before clustering.

\paragraph{Filter dead features and too frequent features}
A feature's activation frequency is the fraction of tokens in a dataset for which
the feature has positive activation. Dead features have activation frequency near
0, while some features activate too frequently. We discard features with
activation frequency below 0.002\% or above 10\%.

\subsection{Clustering}
\label{sec:stage2}
The clustering stage is formulated as a binary integer linear program (ILP)
over the retained feature nodes. The program decides which pairs of features
belong to the same supernode, while embedding and logit nodes are kept outside the
optimization as singleton supernodes. This formulation makes the design explicit:
the objective rewards grouping features with similar signed causal roles, and the
constraints enforce a valid partition, a causal-information budget, a complexity
budget, and a layer-span restriction.

\paragraph{Feature representation.}
Let $F = V'_{\text{feature}} = \{1,\dots,n\}$ be the retained feature nodes after
pruning. A feature's causal role is represented by its signed outgoing and
incoming edge profiles. The formulas below use the implementation convention that
$W_{ku}$ is the edge from source $u$ to target $k$. For a retained feature node
$u \in F$, define
\begin{align}
(v_u^{\text{out}})_k &= W_{ku}\,\sqrt{\mathrm{Inf}_k},
\qquad k \in V', \nonumber\\
(v_u^{\text{in}})_k &= W_{uk}\,\sqrt{\mathrm{Rel}_k},
\qquad k \in V', \nonumber\\
r(u) &= \bigl[\,v_u^{\text{out}};\,v_u^{\text{in}}\,\bigr]
\;\in\; \mathbb{R}^{2|V'|}. \label{eq:role}
\end{align}
The outgoing half records which downstream nodes $u$ influences, weighted by the
influence of those targets. The incoming half records which upstream nodes
influence $u$, weighted by the relevance of those sources. The coordinates keep
the sign of $W$, so features that affect the same targets with opposite signs have
opposing role vectors rather than appearing similar.

\paragraph{ILP data.}
The ILP is built from pairwise constants computed before optimization. The signed
role similarity between two retained features is
\begin{equation}
s_{ij} =
\cos\bigl(r(i), r(j)\bigr)
\;\in\; [-1,1],
\qquad i,j \in F.
\label{eq:sim}
\end{equation}
A resolution threshold $\theta$ converts this similarity into a linear merge cost
$c^{\text{atom}}_{ij} = \theta - s_{ij}$. If $s_{ij} > \theta$, then
$c^{\text{atom}}_{ij} < 0$ and the ILP is rewarded for merging the pair; if
$s_{ij} < \theta$, then $c^{\text{atom}}_{ij} > 0$ and the ILP is penalized for
merging the pair. The implementation may use a fixed value such as $\theta = 0$ or
an adaptive percentile rule such as \texttt{p65}.

The causal-preservation coefficient of a pair is the retained edge mass that would
be hidden if the two features were placed in the same supernode:
\begin{equation}
c^{\text{causal}}_{ij}
=
\frac{|W_{ij}| + |W_{ji}|}
     {\sum_{(u,v)\in E'} |W_{vu}|},
\qquad i,j \in F,\; i<j.
\label{eq:causal-coeff}
\end{equation}
Here both directions are included because either edge becomes internal after a
merge. If the denominator is zero, the causal budget is inactive. A layer-span
constant $\Delta_{\max}$ defines the allowed-pair set
\begin{equation}
\mathcal{P}
=
\{(i,j): i,j \in F,\; i<j,\;
|\operatorname{layer}(i)-\operatorname{layer}(j)| \le \Delta_{\max}\}.
\label{eq:allowed-pairs}
\end{equation}
Pairs outside $\mathcal{P}$ are not allowed to share a supernode.

\paragraph{Decision variables.}
The ILP uses binary pair variables
\begin{equation}
x_{ij} \in \{0,1\},
\qquad (i,j) \in \mathcal{P},
\label{eq:x-variable}
\end{equation}
where $x_{ij}=1$ means that feature nodes $i$ and $j$ are assigned to the same
supernode. To count supernodes, the model also uses binary representative
variables
\begin{equation}
r_i \in \{0,1\},
\qquad i \in F,
\label{eq:r-variable}
\end{equation}
where $r_i=1$ means that $i$ is the lowest-indexed feature in its supernode. The
number of feature supernodes is therefore $K_F = \sum_{i\in F} r_i$.

\paragraph{ILP objective.}
The objective minimizes the signed-cosine atomicity loss:
\begin{equation}
\min_{x,r}
\quad
\sum_{(i,j)\in\mathcal{P}}
(\theta - s_{ij})x_{ij}.
\label{eq:Lstage2}
\end{equation}
This is a linear objective because all similarities and the threshold are fixed
before solving. The formulation does not place $L_{\text{causal}}$ in the
objective with a trade-off weight. Instead, causal preservation is enforced as a
hard constraint, so the solver first respects the permitted hidden edge mass and
then chooses the most atomic partition inside that feasible region.

\paragraph{Partition constraints.}
The pair variables must describe an equivalence relation. For any three features
$i$, $j$, and $k$, transitivity is enforced by triangle inequalities such as
\begin{equation}
x_{ij} + x_{jk} - x_{ik} \le 1,
\qquad
x_{ij} + x_{ik} - x_{jk} \le 1,
\qquad
x_{ik} + x_{jk} - x_{ij} \le 1,
\label{eq:transitivity}
\end{equation}
whenever the corresponding pair variables are present. If one pair is outside
$\mathcal{P}$, the same rule becomes a layer-span exclusion; for example, if
$(i,k)\notin\mathcal{P}$, then $x_{ij}+x_{jk}\le 1$. These constraints prevent the
ILP from assigning $i$ with $j$ and $j$ with $k$ while keeping $i$ and $k$ in
different supernodes.

\paragraph{Representative constraints.}
The representative variables count one and only one lowest-indexed member for each
supernode. For each feature $i$, let
$A_i = \{j<i : (j,i)\in\mathcal{P}\}$ be the allowed earlier features. The
constraints are
\begin{align}
r_i + x_{ji} &\le 1,
\qquad &&i\in F,\; j\in A_i, \label{eq:rep-upper}\\
r_i + \sum_{j\in A_i} x_{ji} &\ge 1,
\qquad &&i\in F. \label{eq:rep-lower}
\end{align}
If feature $i$ is merged with an earlier feature, Eq.~\eqref{eq:rep-upper} forces
$r_i=0$. If it is not merged with any earlier feature, Eq.~\eqref{eq:rep-lower}
forces $r_i=1$. Hence $K_F=\sum_i r_i$ counts feature supernodes without requiring
explicit cluster labels.

\paragraph{Budget constraints.}
The causal-information budget limits the retained edge mass hidden inside
supernodes:
\begin{equation}
\sum_{(i,j)\in\mathcal{P}}
c^{\text{causal}}_{ij}x_{ij}
\le
\varepsilon_{\text{causal}},
\qquad
0 \le \varepsilon_{\text{causal}} \le 1.
\label{eq:causal-budget}
\end{equation}
The complexity budget limits the number of feature supernodes:
\begin{equation}
\sum_{i\in F} r_i \le K_{\max}.
\label{eq:cluster-budget}
\end{equation}
The first budget preserves visible causal edges by preventing too much retained
edge mass from becoming internal to supernodes. The second budget keeps the
summary readable by bounding the number of feature supernodes before embedding and
logit singleton supernodes are added back.

\paragraph{Cluster recovery.}
After the ILP is solved, the feature partition is recovered from the selected
pair variables: all pairs with $x_{ij}=1$ are joined, and the connected components
under these joins become feature supernodes. The transitivity constraints ensure
that these components define a valid partition. Embedding and logit nodes are then
added as singleton supernodes, so the clustering output satisfies the output
conditions of Eq.~\eqref{eq:supernode-conditions}.

\subsection{Interpreting}
\label{sec:stage3}

Interpreting converts the clustered pruned graph into the final summary graph.
This stage takes the partition $f$ from clustering, aggregates retained edges
between supernodes, removes cycles introduced by aggregation, and assigns
human-readable labels.

\paragraph{Block-sum adjacency.}
For each ordered pair of distinct supernodes $(C,C')$, the signed block-sum edge
weight is
\begin{equation}
B_{C \to C'} =
\sum_{u \in C,\, v \in C'} W_{vu}\,\mathbf{1}[(u,v) \in E'].
\label{eq:block-sum}
\end{equation}
This quantity sums all retained attribution-graph edges from members of $C$ to
members of $C'$. The row-column convention is preserved: $W_{vu}$ is the edge
from source $u$ to target $v$. Diagonal blocks are omitted because edges inside a
supernode are represented as part of that node rather than as visible edges in
$H$.

\paragraph{Edge direction}
The first acyclicity step removes two-node cycles. For each unordered pair
$\{C,C'\}$, let $a = B_{C \to C'}$ and $b = B_{C' \to C}$. The method keeps only
the net flow in the direction with larger magnitude:
\begin{equation}
(B_{C \to C'},\, B_{C' \to C}) \leftarrow
\begin{cases}
\bigl((|a|-|b|)\,\mathrm{sgn}(a),\,0\bigr) & \text{if } |a| > |b|, \\[2pt]
\bigl(0,\,(|b|-|a|)\,\mathrm{sgn}(b)\bigr) & \text{if } |b| > |a|, \\[2pt]
(0,\,0) & \text{if } |a| = |b|.
\end{cases}
\label{eq:edgedir}
\end{equation}
This rule removes every two-node cycles and leaves an edge only when one
direction has nonzero net dominance.

\paragraph{Back-edge removal.}
The second acyclicity step removes longer cycles by imposing a depth order on the
supernodes. Embedding supernodes receive depth $-\infty$, logit supernodes receive
depth $+\infty$, and each feature supernode receives the median layer of its
member features. Ties are broken by mean member layer, then by the smallest member
$\text{ctx\_idx}$, and finally by supernode index. After sorting by this order, the
method deletes every edge $C \to C'$ whose source ranks after its target. The
remaining adjacency is the summary adjacency $W_H$, and the final edge set is
\[
E_H = \{(C,C') : W_{H,\,C \to C'} \ne 0\}.
\]
By construction, all surviving edges point forward in the imposed order, so $H$ is
a DAG.

\paragraph{Labeling.}
Labeling adds display metadata to the acyclic summary graph: each feature
supernode receives a short label, a role, and a one-sentence description. The
implementation sends an LLM the original prompt, the predicted token, and compact
feature evidence for each supernode, including layer, token position, activation
examples, neighboring tokens, and top positive logits. The returned JSON assigns
one of four roles --- Input, Abstract, Output, or Trash --- and does not change
$V_H$, $E_H$, or $W_H$; prompt details are deferred to the Appendix.

\section{Chapter Summary}

This chapter formalized attribution-graph summarization and defined the proposed
three-stage method. The input is a signed directed acyclic attribution graph, and
the output is a directed acyclic summary graph whose supernodes partition a
retained subset of non-error nodes. The method first prunes the attribution graph
using influence, relevance, and the pruning loss $L_{\text{prune}}$. It then
clusters retained feature nodes by a binary ILP whose pair variables encode
same-supernode assignments. The ILP minimizes a signed-cosine atomicity objective
subject to transitivity, representative-counting, causal-information, complexity,
and layer-span constraints. Finally, it aggregates the clustered graph with
block-sum edge weights, removes cycles, and labels the resulting supernodes for
inspection. The next chapter analyzes properties of this construction, and Chapter
5 evaluates whether the resulting summary graphs are faithful to the replacement
model under steering interventions.
