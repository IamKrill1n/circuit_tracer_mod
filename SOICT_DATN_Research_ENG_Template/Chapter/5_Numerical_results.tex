\section{Overview}

Chapter 4 analyzed why the proposed proxy objectives should preserve the causal
information of an attribution graph while reducing its size. Chapter 5 evaluates
whether this happens in practice. The chapter first describes the datasets, the
experimental setup, and the evaluation methodology used for pruning, clustering,
and steering validation. It then defines the baselines used for comparison. All
numerical results are reported together at the end, so the reader can first see
what is being measured and then compare the outcomes.

\section{Datasets}
\label{sec:datasets}

\subsection{Synthetic analogies from BATS}
The main evaluation uses synthetic analogy prompts built from the Bigger Analogy
Test Set (BATS). BATS is a benchmark for probing relational and semantic
knowledge in word embeddings and language models. We use entities from its
lexicography category and construct prompts of the form ``The saying goes: $A$
is to $B$ as $C$ is to $D$'', where $A$, $B$, $C$, and $D$ come from the same
subcategory. The model must predict $D$ from the relation expressed by
$A \to B$ and the query entity $C$.

The analogy setting is useful because the prompt contains both syntactic
scaffolding and semantic relation information. A good summary should keep the
features that carry the relation and predicted answer, while pruning or
absorbing features that only track punctuation, stop words, or prompt format.
For the quantitative pruning and clustering experiments, we keep prompts that
the model answers correctly with confidence above $20\%$. This filter ensures
that every attribution graph explains a prediction the model actually makes.

\subsection{Multi-hop reasoning}
The second dataset follows the multi-hop queries of Ameisen et
al.~\cite{ameisen2025circuit}. Each prompt requires several reasoning steps
before reaching the answer, so it tests whether the summary pipeline can preserve
causal structure beyond a single local association. These graphs are used as a
qualitative stress test for the summarization pipeline and viewer, while the
reported quantitative tables focus on the analogy graphs where enough examples
are available for controlled sweeps.

\section{Experimental Setup}
\label{sec:setup}

\subsection{Environment}
Experiments run on a single workstation with an NVIDIA GeForce RTX 4090 GPU
(24\,GB VRAM) and 64\,GB of RAM, under Ubuntu 22.04 LTS. The implementation uses
Python 3.13.5. Attribution graphs are generated and evaluated with the
circuit-tracing library of Ameisen et al.~\cite{ameisen2025circuit}. The summary
graphs reuse the same feature metadata and are rendered with an adapted version
of the attribution-graph viewer.

\subsection{Pipeline configuration}
Unless stated otherwise, pruning uses the influence--relevance importance score
from Chapter~3 with an edge retained-mass threshold of $0.95$. The pruning sweep
varies the node retained-mass threshold and the mixture parameter $\alpha$ in
Eq.~\eqref{eq:importance}. The clustering experiments use pruned analogy graphs
from the $\alpha=0.5$ condition, which balances downstream influence and upstream
relevance. The exact clusterer is the binary integer linear program (ILP) of
Eq.~\eqref{eq:Lstage2}, solved through SciPy's \texttt{milp} interface to the
HiGHS mixed-integer solver with an explicit time limit. Thus the mathematical
model is an ILP, while the software backend is a mixed-integer solver.

\section{Evaluation Methodology}
\label{sec:eval-method}

\subsection{Pruning metrics}
Pruning is evaluated by measuring whether the retained subgraph preserves the
replacement-model computation and whether it removes syntactic scaffolding. Let
$I_i$ denote the influence of node $i$ after pruned features are merged into
their same-position error nodes, let $\ell_i$ be the logit weight, and let
$A^{\mathrm{norm}}$ be the normalized adjacency used for completeness scoring.

\paragraph{Replacement score.}
Replacement score measures how much output influence comes from token nodes
rather than reconstruction-error nodes after pruning. With embedding indices
$V_{\mathrm{emb}}$ and error indices $V_{\mathrm{err}}$, it is
\begin{equation}
\mathrm{Rep}
=
\frac{\sum_{i \in V_{\mathrm{emb}}} I_i}
     {\sum_{i \in V_{\mathrm{emb}}} I_i + \sum_{i \in V_{\mathrm{err}}} I_i}.
\label{eq:metric-replacement}
\end{equation}
Higher replacement score means that the retained graph explains more of the
target computation through features and input tokens instead of error nodes.

\paragraph{Graph completeness.}
Graph completeness measures the weighted fraction of computation that remains on
non-error pathways. Let
$q_i = 1 - \sum_{e \in V_{\mathrm{err}}} A^{\mathrm{norm}}_{ie}$ be the fraction
of node $i$'s normalized outgoing mass that does not go to error nodes. The score
is
\begin{equation}
\mathrm{Comp}
=
\frac{\sum_i q_i (I_i + \ell_i)}
     {\sum_i (I_i + \ell_i)}.
\label{eq:metric-completeness}
\end{equation}
Higher graph completeness means that pruning has not moved important computation
into reconstruction-error channels.

\paragraph{Token attribution faithfulness.}
Token attribution faithfulness measures how much of each selected input token's
flow to the target logit survives pruning. If $\tau_t$ is the weight of input
token $t$, $R^{\mathrm{full}}_{t \to y}$ is its full-graph relevance reaching the
target logit, and $R^{\mathrm{pruned}}_{t \to y}$ is the same quantity after
masking to the retained nodes and edges, then
\begin{equation}
\mathrm{TAF}
=
\frac{\sum_t \tau_t
       \frac{R^{\mathrm{pruned}}_{t \to y}}
            {R^{\mathrm{full}}_{t \to y}}}
      {\sum_t \tau_t}.
\label{eq:metric-token-faith}
\end{equation}
Higher token attribution faithfulness means that pruning preserves the
input-to-output attribution pattern, although the main pruning figures below
omit this metric to focus on graph-level faithfulness.

\paragraph{Syntactic feature rate.}
The syntactic feature rate measures how much of the retained explanation is
devoted to prompt scaffolding. If $S$ is the set of retained features manually
classified as punctuation, stop-word, inflection, word-order, or prompt-format
features, and $F'$ is the retained feature set, then
\begin{equation}
\mathrm{SynRate} = \frac{|S|}{|F'|}.
\label{eq:metric-syntax}
\end{equation}
Lower syntactic feature rate indicates a more compact semantic explanation at
the same graph size.

\subsection{Clustering metrics}
Clustering is evaluated on 100 pruned analogy graphs. All clustering methods are
matched to the same number of feature supernodes as the proposed summary on each
graph, so the comparison isolates partition quality rather than graph size. Let
$F'$ be the retained feature nodes, let $f(i)$ be the supernode containing
feature $i$, let $r(i)$ be the role vector of Chapter~3, and let $W'$ be the
pruned adjacency.

\paragraph{Raw silhouette.}
Raw silhouette measures geometric compactness in role-vector space. With
$a_i$ the average cosine distance from $r(i)$ to features in the same cluster and
$b_i$ the smallest average cosine distance to another cluster, the score is
\begin{equation}
\mathrm{Sil}
=
\frac{1}{|F'|}
\sum_{i \in F'}
\frac{b_i - a_i}{\max(a_i, b_i)}.
\label{eq:metric-silhouette}
\end{equation}
Higher silhouette means clusters are geometrically tighter, but this metric does
not by itself test causal coherence.

\paragraph{Downstream effect gap.}
Downstream effect gap compares causal-effect similarity within supernodes against
similarity across supernodes. Let $d_i$ be the nonnegative outgoing effect profile
of feature $i$ over downstream nodes, and let $\mathcal{P}_{\mathrm{in}}$ and
$\mathcal{P}_{\mathrm{out}}$ be the within-cluster and cross-cluster feature
pairs. The score is
\begin{equation}
\mathrm{DownGap}
=
\frac{1}{|\mathcal{P}_{\mathrm{in}}|}
  \sum_{(i,j)\in\mathcal{P}_{\mathrm{in}}}\cos(d_i,d_j)
-
\frac{1}{|\mathcal{P}_{\mathrm{out}}|}
  \sum_{(i,j)\in\mathcal{P}_{\mathrm{out}}}\cos(d_i,d_j).
\label{eq:metric-downgap}
\end{equation}
Higher downstream effect gap means that members of a supernode affect later nodes
more similarly than features outside the supernode.

\paragraph{Signed downstream effect gap.}
Signed downstream effect gap repeats the previous calculation with signed
outgoing profiles $\tilde d_i$:
\begin{equation}
\mathrm{SignedDownGap}
=
\overline{\cos(\tilde d_i,\tilde d_j)}_{(i,j)\in\mathcal{P}_{\mathrm{in}}}
-
\overline{\cos(\tilde d_i,\tilde d_j)}_{(i,j)\in\mathcal{P}_{\mathrm{out}}}.
\label{eq:metric-signed-downgap}
\end{equation}
Higher signed downstream effect gap indicates that clusters avoid merging
features with similar targets but opposite causal signs.

\paragraph{Internalized edge mass.}
Internalized edge mass measures how much fine-grained causal weight disappears
inside supernodes. It is
\begin{equation}
\mathrm{Internalized}
=
\frac{\sum_{(u,v)\in E':\, f(u)=f(v)} |W'_{vu}|}
     {\sum_{(u,v)\in E'} |W'_{vu}|}.
\label{eq:metric-internalized}
\end{equation}
Lower internalized edge mass means that more retained causal structure remains
visible as edges between supernodes.

\paragraph{DAG loss.}
DAG loss measures the edge mass removed when the raw supernode graph is converted
into a DAG. If $M_{\mathrm{raw}}$ is the sum of absolute raw superedge weights
before cycle removal and $M_{\mathrm{dag}}$ is the same sum after cycle removal,
then
\begin{equation}
\mathrm{DAGLoss}
=
\frac{M_{\mathrm{raw}} - M_{\mathrm{dag}}}{M_{\mathrm{raw}}}.
\label{eq:metric-dagloss}
\end{equation}
Lower DAG loss means the partition is more compatible with the final acyclic
summary graph.

\subsection{Steering metrics}
Steering validates the final summary graph directly. For each non-fixed
supernode $C$, we negate every member feature by setting its activation to
$M \cdot a$ with steer factor $M=-1$ and clean activation $a$. The constrained
patch writes only through the direct-effect layer window $[l,l+1]$, while
attention patterns and LayerNorm scales are frozen as in Ameisen et
al.~\cite{ameisen2025circuit}.

\paragraph{Sign consistency.}
Sign consistency measures whether summary edges predict the direction of
downstream responses. For each measurable summary edge $e=(C,C')$, let $w_e$ be
its edge weight, let $\Delta a_C$ be the source activation change, and let
$m_e$ be the measured downstream sign. The predicted sign is
$p_e=\operatorname{sgn}(w_e)\operatorname{sgn}(\Delta a_C)$, and the metric is
\begin{equation}
\mathrm{SignCons}
=
\frac{\sum_e |w_e|\,\mathbf{1}[p_e=m_e]}
     {\sum_e |w_e|}.
\label{eq:metric-signcons}
\end{equation}
Higher sign consistency means the directed signed edges of the summary graph
match intervention responses.

\paragraph{Edge-effect Spearman correlation.}
Edge-effect correlation tests whether larger summary edges produce larger
measured responses. For positive feature-target edges, with response magnitude
$g_e = |1-\rho_e|$ from activation ratio $\rho_e$, the metric is
\begin{equation}
\rho_{\mathrm{edge}}
=
\mathrm{Spearman}\bigl(\{|w_e|\}_e,\{g_e\}_e\bigr).
\label{eq:metric-spearman}
\end{equation}
Higher correlation means summary edge magnitude is more aligned with measured
intervention strength.

\paragraph{Target probability change.}
Target probability change measures how strongly steering a supernode changes the
model's predicted answer. If $\Delta p_y(C)$ is the target-token probability
change after steering source supernode $C$, then
\begin{equation}
\Delta p_{\mathrm{target}}
=
\frac{1}{|\mathcal{C}|}
\sum_{C\in\mathcal{C}} |\Delta p_y(C)|.
\label{eq:metric-target-delta}
\end{equation}
Larger values indicate that the summary contains supernodes with causal access to
the target prediction.

\section{Baselines}
\label{sec:baselines}

\subsection{Influence-only pruning}
Influence-only pruning is the direct pruning baseline for the proposed
influence--relevance score. It sets $\alpha=0$ in Eq.~\eqref{eq:importance}, so a
node is ranked only by downstream reach to the target logit. This baseline tests
whether adding upstream token relevance improves the semantic focus of the
retained graph without sacrificing replacement score or graph completeness.

\subsection{Spectral clustering on role vectors}
Spectral clustering on role vectors uses the same role-vector representation as
the proposed clusterer, but replaces the ILP objective with a standard spectral
partitioning algorithm. The affinity is a rectified cosine similarity between
role vectors. This baseline tests whether a generic graph-free clustering method
can recover comparable supernodes from the same feature representation.

\subsection{K-means on role vectors}
K-means on role vectors first unit-normalizes each role vector and then minimizes
Euclidean within-cluster variance. After normalization, Euclidean distance is a
cosine-distance surrogate, so this is a strong geometric compactness baseline.
It tests whether tight role-vector clusters are sufficient for causal summary
quality.

\subsection{Spectral clustering on adjacency}
Spectral clustering on adjacency ignores the role vectors and instead uses the
symmetrized absolute pruned adjacency matrix as its affinity. It groups features
that are strongly connected in the retained graph. This baseline tests whether
connectivity alone is enough, without the incoming and outgoing role profiles
used by the proposed method.

\subsection{Random same-size clusters}
The random same-size baseline keeps the same feature-cluster size distribution
as the proposed summary but randomly assigns features to clusters. It controls
for the effect of cluster count and cluster sizes. Any method that does not beat
this baseline is not extracting causal or geometric structure from the graph.

\subsection{K-means steering baseline}
For steering validation, K-means is also evaluated with the same number of
feature supernodes as the ILP summary on each graph. This comparison asks whether
the final summary graph remains intervention-faithful when the partition is
chosen by a simple geometric baseline rather than by the ILP objective.

\subsection{Clustering results}
Table~\ref{tab:clustering-baseline-entmax} reports clustering metrics on 100
entmax-pruned analogy graphs. K-means obtains the highest raw silhouette score,
which confirms that it forms geometrically compact clusters in role-vector
space. However, this compactness does not translate into the strongest causal
coherence. The proposed ILP summary has the largest downstream effect gap and
the largest signed downstream effect gap, meaning that features grouped inside
one supernode tend to affect the rest of the graph in a more similar signed
direction than features in different supernodes.

The edge-mass metrics show the same pattern from a structural angle. The ILP
summary has the lowest internalized edge mass and the lowest DAG loss, so it
hides the least fine-grained edge mass inside supernodes and loses the least
superedge mass during acyclic graph construction. Since internalized mass is
explicitly constrained by the ILP, the most independent evidence for coherent
supernodes is the downstream-effect gap; the mass metrics show that this
coherence is achieved while preserving visible causal structure.

Table~\ref{tab:steering-ilp-kmeans} summarizes the steering evaluation on 100
softmax-pruned analogy graphs with $\alpha=0.5$ and node threshold $0.02$. Both

which means most signed summary edges predict the direction of the measured
intervention response. K-means is stronger on this steering metric, while the ILP
is stronger on structural preservation in Table~\ref{tab:clustering-baseline-entmax}.
The result suggests that intervention faithfulness is partly a property of the
summary abstraction itself, not only of one clustering solver.

The steering results should be read together with the clustering table. K-means
produces compact role-vector clusters and strong intervention signs, but it
internalizes more edge mass and loses more mass during DAG construction. The ILP
keeps more causal structure visible in the final graph, at the cost of slightly
weaker intervention correlations in this matched-size steering test. This is the
main empirical trade-off exposed by the experiments.

\section{Chapter Summary}

This chapter defined the experimental protocol before presenting the results. The
evaluation uses BATS-derived analogy prompts as the main quantitative dataset
and multi-hop prompts as a qualitative stress test. Pruning is measured by
replacement score, graph completeness, token attribution faithfulness, and
syntactic feature rate; clustering is measured by role-vector compactness,
downstream-effect coherence, internalized edge mass, and DAG loss; steering is
measured by sign consistency, edge-effect rank correlation, and probability
changes. The results show that influence--relevance pruning preserves
graph-level faithfulness while allowing more semantic selection, that the ILP
clusterer yields the strongest downstream-effect coherence and lowest structural
loss among the clustering baselines, and that both ILP and K-means summaries
produce intervention-faithful signed edges. Chapter 6 discusses the limitations
of these results and the remaining gap between structural preservation and
steering performance.
