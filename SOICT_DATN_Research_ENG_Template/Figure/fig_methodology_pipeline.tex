\caption[The three-stage summarization pipeline.]{The three-stage
summarization pipeline. \textbf{Input:} the attribution graph $G$ is a dense
DAG over embedding ($\diamond$), feature ($\circ$), error ($\triangle$), and
logit ($\square$) nodes. \textbf{Stage~1 (prune)} discards every error node and
every node off a strong input-to-logit pathway, leaving the compact subgraph
$(V',E')$. \textbf{Stage~2 (cluster)} groups the surviving feature nodes into
supernodes (ellipses); embedding and logit nodes stay singletons.
\textbf{Stage~3 (interpret)} aggregates the pruned edges, forces the supernode
graph to be acyclic, and labels each supernode, yielding the readable summary
graph $H$ --- here the ``Dallas $\to$ Texas $\to$ Austin'' multi-step circuit.}
\label{fig:methodology-pipeline}
